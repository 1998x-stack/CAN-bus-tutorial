# 🚌 CAN总线 · 从入门到精通

> 📘 30章 实战体系

一套完整的 **CAN总线 · 从入门到精通** 全中文实战课程体系，共 **30 章**。本课程以 HTML 可视化的形式呈现，从基础原理到工程实践循序渐进，适合系统性学习与复习。

## 🚀 快速开始

无需安装任何依赖，直接用浏览器打开 `index.html` 即可在线阅读全部章节：

```bash
open index.html   # macOS
# 或在浏览器中直接打开 index.html
```
